# AES-256-GCM File Encryptor

## Жоба туралы (About)
Бұл жоба Java тілінде әзірленген файлдарды шифрлау және шифрын шешу (Encrypt/Decrypt) бағдарламасы. Оның мақсаты — құпия деректерді заманауи криптографиялық стандарттар арқылы қорғау.

## Қолданылатын технологиялар (Technologies):
- Java (JDK)
- Maven (Build system)
- Java Cryptography Architecture (JCA) - PBKDF2, SecureRandom, AES

## Атқарылған жұмыстар (Progress):
- Құпия сөзден криптографиялық кілт алу логикасы (PBKDF2WithHmacSHA256) іске қосылды.
- Қауіпсіз кездейсоқ тұз (Salt) пен SecureRandom генерациясы конфигурацияланды.
